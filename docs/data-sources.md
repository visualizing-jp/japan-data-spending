# データソース

「日本人は何にお金を使ってきたか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-05。軸・件数は e-Stat API のメタ取得・実測で確認済み。

## 1. 結論

家計の費目構造の変化（食費・住居・教育・通信・教養娯楽など）を、**時代 / 費目 / 属性**の3ビューで見せる。
一次ソースは総務省「家計調査」家計収支編・**二人以上の世帯**・用途分類（年次）。
第1版は全国の月平均金額（円）と、消費支出に占める構成比。属性は世帯主の年齢階級。

| ビュー | 一次ソース | 統計表ID | 次元 | 指標・単位 |
| --- | --- | --- | --- | --- |
| 時代 | 用途分類（総数） | `0002070003` | 費目×年 | 月平均円、構成比 |
| 費目 | 同上 | `0002070003` | L4費目×年 | 月平均円、構成比 |
| 属性 | 用途分類（世帯主の年齢階級別） | `0002070011` | 年齢×費目×年 | 月平均円、構成比 |

出典表記: 総務省「家計調査」（e-Stat）。

## 2. 採用データセット（メタ・実測）

政府統計コード `00200561`。統計名はいずれも「家計調査 家計収支編 二人以上の世帯」。

### `0002070003` — 用途分類 用途分類（総数）

- 軸: 表章項目(金額) × 用途分類(265) × 世帯区分(4) × 地域(75) × 年次(41: 1985–2025)
- 全軸の積は約 326 万セル。取得時は用途・世帯区分・全国に絞る（API の `cdCat01` / `cdCat02` / `cdArea`）
- 採用世帯区分:
  - `01` 二人以上の世帯（農林漁家世帯を除く）… **1985–1999**（実測は 1985–2017 まで値あり）
  - `03` 二人以上の世帯（2000年～）… **2000–2025**
- 2000年の接続: `01` と `03` は農林漁家の扱いが異なる。配信は年ごとに片側だけ使い、境界を注記する
- 地域は第1版で **全国 (`00000`)** のみ

### `0002070011` — 用途分類 用途分類（世帯主の年齢階級別）

- 軸: 金額 × 用途分類(265) × 世帯区分(4) × 年齢階級(18) × 全国 × 年次(41)
- 採用世帯区分: `03`（2000–2025）
- 年齢: `A00` 平均、`425` 24歳以下、5歳階級 `205`–`216`、`580` 85歳以上、合算 `565` 65歳以上 / `570` 70歳以上
- 除外: `435` 34歳以下（25–34 と重複）
- 実測: 24歳以下・25–34歳・70歳以上合算は標本が小さく、費目によって欠測が多い。35歳以上の5歳階級は概ね揃う

### 用途分類（採用コード）

消費支出の分母と L4 十大費目、物語用 L5、エンゲル係数。

| コード | 名称 | レベル | 用途 |
| --- | --- | --- | --- |
| `059` | 消費支出 | L3 | 構成比の分母 |
| `060` | 食料 | L4 | 時代・費目・属性 |
| `102` | 住居 | L4 | 同上 |
| `107` | 光熱・水道 | L4 | 同上 |
| `112` | 家具・家事用品 | L4 | 同上 |
| `122` | 被服及び履物 | L4 | 同上 |
| `140` | 保健医療 | L4 | 同上 |
| `145` | 交通・通信 | L4 | 同上 |
| `152` | 教育 | L4 | 同上 |
| `156` | 教養娯楽 | L4 | 同上 |
| `165` | その他の消費支出 | L4 | 同上 |
| `098` | 外食 | L5 | 時代のみ |
| `103` | 家賃地代 | L5 | 時代のみ |
| `151` | 通信 | L5 | 時代のみ |
| `153` | 授業料等 | L5 | 時代のみ |

L4 十大費目の金額合計は消費支出に一致する（再掲は含めない）。L5 は親費目の内訳であり、構成比ランキングには入れない。

| 指標 | 1985 (`01`) | 2000 (`03`) | 2025 (`03`) |

| 消費支出 | 273,114 | 317,328 | 314,001 |
| 食料 | 73,735 | 73,954 | 89,754 |
| 通信 | 5,604 | 9,521 | 11,661 |
| 教育 | 10,853 | 13,921 | 11,936 |

## 3. 見送り（第1版）

| 候補 | 理由 |
| --- | --- |
| 品目分類（2020/2025年改定など） | 改定ごとに系列が切れる。用途分類の十大費目の方が長期接続しやすい |
| 総世帯・単身の用途分類 | 二人以上の長期系列と定義がずれる。第1版は二人以上に固定 |
| 都市階級・地方のみの総世帯表 `0003000808` | 世帯類型が異なり、期間も 2007年〜 |
| 年収五分位 `0002070005` | 属性は年齢を優先（教育・医療の物語が明確） |
| 都道府県庁所在市の個別系列 | 標本が小さく、第1版の問い（全国構造）から外れる |
| 勤労者世帯のみ (`04`/`02`) | 総数系列で足りる。拡張用 |

## 4. 指標・分母

- **金額** = 世帯あたり月平均（円）。年平均の公表値
- **構成比** = 当該費目金額 / 消費支出（`059`）。小数4桁
- **エンゲル係数** = 公表値（％）を ÷100。消費支出シェアの再計算ではない
- L4 同士は足してよい。L4 と L5、または再掲行は同時に足さない

## 5. 配信ファイル

`scripts/build.ts` → `public/data/`

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | item × year | yen, share | items（L4+L5+engel） |
| `item.json` | item × year | yen, share | items（L4 のみ） |
| `attrs.json` | age × item × year | yen, share | ages, items（L4） |

cube 形式は `dims` + `measures`（行優先）+ 辞書。欠測は `null`。年は西暦文字列。

## 6. 注記（UIに短く出す）

- 二人以上の世帯。単身は含まない
- 2000年に農林漁家世帯を含む定義へ切替（`01`→`03`）
- 金額は名目の月平均。物価補正は第1版では行わない
- 住居は家賃・修繕等。持ち家の帰属家賃は含まない（調査定義どおり）
- エンゲル係数は公表系列。食料シェアと小数点以下で一致しない場合がある
- 若年の年齢階級は標本が小さく欠測になりうる

## 7. 更新手順

```
npm run meta
npm run fetch
npm run data
npm run verify
```

`ESTAT_APP_ID` は `.env` に置く（コミットしない）。生レスポンスは `data/raw/`（gitignore）。配信用 JSON は追跡する。
